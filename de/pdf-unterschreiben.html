PDF unterschreiben

Unterschreibe Verträge, Formulare oder Briefe, ohne zu drucken oder zu scannen: zeichnen, tippen oder ein Foto deiner Unterschrift auf Papier nutzen.

  • Ohne Datei-Upload
  • Kostenlos, ohne Anmeldung
  • Läuft im Browser

Ein PDF in 3 Schritten unterschreiben

  1. Wähle das PDF, das du unterschreiben möchtest.
  2. Erstelle deine Unterschrift: zeichne sie, tippe deinen Namen oder lade ein Foto deiner Unterschrift auf Papier hoch.
  3. Zieh sie an ihren Platz, passe die Größe an (du kannst sie auf allen Seiten wiederholen) und tippe auf „PDF unterschreiben“.

Deine Dateien verlassen dein Gerät nicht

Anders als andere Online-Werkzeuge lädt DocuSmart deine Dokumente auf keinen Server hoch: Alles wird in deinem Browser verarbeitet. Du kannst es bedenkenlos mit Verträgen, Rechnungen oder Ausweisdokumenten nutzen. Unsere Datenschutzerklärung lesen (auf Spanisch).

Häufige Fragen

Ist das rechtsgültig?

Es ist eine einfache elektronische Signatur: das Bild deiner Unterschrift auf dem Dokument, wie handschriftlich unterschreiben. Für die meisten Alltagsvorgänge reicht das; wird eine qualifizierte Signatur mit Zertifikat verlangt, brauchst du einen Vertrauensdiensteanbieter.

Wird meine Unterschrift irgendwo gespeichert?

Nein. Unterschrift und PDF werden in deinem Browser verarbeitet und auf keinen Server hochgeladen. Beim Schließen der Seite wird die Unterschrift gelöscht.

Kann ich mehrere Seiten unterschreiben?

Ja. Füge die Unterschrift auf jeder gewünschten Seite hinzu oder nutze „Auf allen Seiten wiederholen“, um das ganze Dokument zu paraphieren.

Wie mache ich ein gutes Foto meiner Unterschrift?

Unterschreibe mit dunkler Tinte auf weißem Papier und fotografiere bei gutem Licht ohne Schatten. DocuSmart entfernt den weißen Hintergrund automatisch.
