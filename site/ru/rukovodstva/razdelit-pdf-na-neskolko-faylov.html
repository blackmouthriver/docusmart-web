Как разделить PDF на несколько файлов или извлечь только нужные страницы

Портал просит только страницу с подписью, или PDF на 80 страниц не проходит по почте. Вот как разделить PDF на части или извлечь только нужные страницы прямо в браузере.

4 мин чтенияОбновлено 25 ноября 2026 г.

Шесть способов разделить

Прежде чем начать, решите, что именно нужно: у инструмента Разделить PDF есть режим для каждого случая.

  • Выбрать страницы: коснитесь миниатюр (или введите «1-3, 5») — получится PDF только с этими страницами.
  • По диапазонам: несколько диапазонов сразу, и каждый сохраняется отдельным PDF.
  • Каждые N страниц: равные части, например по 10 страниц.
  • По закладкам: отдельный PDF для каждой главы, если в документе есть оглавление из закладок.
  • По размеру: части не тяжелее заданного веса — для почты или порталов с ограничением.
  • Каждая страница отдельно: по одному PDF на страницу.

Пошагово

Откройте Разделить PDF и выберите файл. Появятся миниатюры его страниц. В режиме «Выбрать страницы» коснитесь тех, что хотите забрать: они подсветятся синим, а поле сверху заполнится само.

Нажмите кнопку внизу. Когда всё будет готово, результат появится рядом с оригиналом, чтобы его можно было проверить, и вы скачаете его под любым именем. Если режим создаёт несколько файлов, их можно скачать по одному или все сразу в ZIP-архиве.

Чтобы взять отдельные страницы из нескольких PDF и собрать их в один, быстрее воспользоваться инструментом Объединить PDF: там можно выбрать, какие страницы взять из каждого файла.

Если части всё ещё слишком тяжёлые

Разделение не влияет на качество: каждая страница копируется как есть. Если какая-то часть всё равно больше лимита, выберите режим По размеру или пропустите её через Сжать PDF. Одна страница, отсканированная в высоком разрешении, сама по себе может весить больше лимита — тогда поможет только сжатие.

Частые случаи

  • Портал просит только паспорт или удостоверение с двух сторон: выберите эти две страницы и загрузите только этот PDF.
  • Выписка за весь год: если в ней есть закладки по месяцам, используйте По закладкам, если нет — Каждые N страниц.
  • Почта с лимитом 10 МБ: выберите По размеру, укажите 10, и каждая часть уложится в лимит.

Документ не покидает ваше устройство

Разделение выполняется в браузере: PDF не загружается ни на какой сервер. Поэтому так можно работать с выписками, медицинскими картами или договорами, не оставляя их копий где-то ещё.

Кратко

  1. Откройте «Разделить PDF». Откройте инструмент «Разделить PDF» на docusmart.online и выберите файл.
  2. Выберите режим. Выбрать страницы, по диапазонам, каждые N страниц, по закладкам, по размеру или каждая страница отдельно.
  3. Отметьте страницы. Коснитесь миниатюр или введите номера (например, 1-3, 5).
  4. Разделите и скачайте. Нажмите кнопку и скачайте результат или все файлы в одном ZIP-архиве.

Частые вопросы

Теряется ли качество при разделении?

Нет. Страницы копируются как есть, с исходным текстом и изображениями.

Можно ли разделить PDF с паролем?

Если у него только ограничения (он открывается без пароля), то да. Если для открытия нужен пароль, сначала снимите его через «Разблокировать PDF».

Что происходит с закладками?

В режиме «По закладкам» каждая глава оглавления сохраняется отдельным PDF с названием закладки.
