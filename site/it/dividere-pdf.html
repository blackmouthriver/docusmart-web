Dividere PDF

Estrai le pagine che ti servono o separa ogni pagina in un file a sé, direttamente nel browser.

  • Senza caricare i tuoi file
  • Gratis e senza registrazione
  • Funziona nel browser

Come dividere un PDF in 3 passi

  1. Scegli il PDF da dividere.
  2. Tocca le pagine da tenere, scrivi un intervallo come "1-3, 5" oppure scegli "Ogni pagina separata".
  3. Scarica il risultato: un PDF con le pagine scelte o uno .zip con una pagina per file.

I tuoi file non lasciano il tuo dispositivo

A differenza di altri strumenti online, DocuSmart non carica i tuoi documenti su nessun server: tutto viene elaborato nel tuo browser. Puoi usarlo con contratti, fatture o documenti d’identità in totale tranquillità. Leggi la nostra informativa sulla privacy (in spagnolo).

Domande frequenti

Come estraggo solo alcune pagine?

Toccale nelle miniature o scrivi un intervallo, per esempio "2-4, 7", oppure "5-" per andare dalla pagina 5 alla fine.

Il PDF originale viene modificato?

No. Viene sempre creato un file nuovo; l’originale resta uguale sul tuo dispositivo.

È sicuro per documenti privati?

Sì. Il file non viene caricato su internet: tutto avviene nel tuo browser.
