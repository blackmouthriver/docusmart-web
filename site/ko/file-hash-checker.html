해시 계산 및 검증(SHA-256, MD5)

문서가 수정되지 않았는지 확인하세요. 디지털 지문을 계산하고, 받은 값과 대조하거나 두 파일을 비교할 수 있으며 파일은 기기 밖으로 나가지 않습니다.

  • 파일 업로드 없음
  • 무료, 가입 불필요
  • 브라우저에서 작동

파일 해시를 계산하거나 검증하는 3단계

  1. "계산", "검증", "비교" 중 하나를 고르고 파일을 추가하세요(PDF, 사진, ZIP 등 모든 형식).
  2. 알고리즘을 고르거나(SHA-256 권장) 받은 해시를 붙여 넣으세요. SHA-256, SHA-512, SHA-1, MD5 중 무엇인지 DocuSmart가 알아서 인식합니다.
  3. 해시를 복사하거나 목록 또는 PDF 무결성 인증서를 다운로드하거나, 일치하는지 확인하세요.

파일이 내 기기 밖으로 나가지 않습니다

다른 온라인 도구와 달리 DocuSmart는 문서를 어떤 서버에도 올리지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다. 계약서, 청구서, 신분증도 안심하고 다룰 수 있습니다. 개인정보 처리방침 보기(스페인어).

자주 묻는 질문

해시란 무엇인가요?

파일의 디지털 지문입니다. 내용으로부터 계산되는 문자와 숫자의 나열로, 파일이 단 1바이트라도 바뀌면 해시는 완전히 달라집니다.

어디에 쓰나요?

받은 문서가 원본과 같은지(계약서, 입찰 서류, 증거 자료, 다운로드 파일) 확인하거나, 특정 날짜의 파일 상태를 기록하거나, 열어 보지 않고 두 파일이 같은지 알아볼 때 씁니다.

어떤 알고리즘을 써야 하나요?

SHA-256이 현재 표준이며 권장됩니다. SHA-512는 더 깁니다. MD5와 SHA-1은 공개된 체크섬과 비교하는 데는 쓸 수 있지만 위조에 대해서는 더 이상 안전하지 않습니다.

무결성 인증서란 무엇인가요?

파일의 이름, 크기, 날짜, 해시가 담긴 PDF입니다. 나중에 누군가 파일을 수정하면 해시를 다시 계산했을 때 인증서의 값과 일치하지 않습니다.

파일이 업로드되나요?

아니요. 해시는 브라우저 안에서 계산되므로 파일이 기기 밖으로 나가지 않습니다.
