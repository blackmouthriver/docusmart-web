PDF에 페이지 번호를 넣는 방법

논문, 보고서, 서류철은 페이지 번호가 있어야 훨씬 검토하기 쉽습니다. 번호가 없는 PDF에 요구받은 형식대로 번호를 매기는 방법입니다.

3분 분량2026년 11월 25일 업데이트

단계별 방법

PDF 페이지 번호 매기기를 열고 PDF를 고릅니다. 번호가 들어갈 위치(위나 아래, 왼쪽·가운데·오른쪽)와 형식("1", "1 / 10", "10페이지 중 1페이지")을 고르세요.

"페이지 번호 매기기"를 누릅니다. 전후 모습이 페이지별로 나란히 보이니 번호가 내용을 가리지 않는지 확인한 뒤 다운로드하세요.

흔한 상황을 해결하는 옵션

  • 처음 페이지 번호 생략: 1을 입력하면 표지에 번호가 들어가지 않습니다. 목차나 헌사가 있다면 더 큰 수를 넣으세요.
  • 시작 번호: 다른 문서에 이어 번호를 매길 때, 예를 들어 25부터 시작합니다.
  • 텍스트: "No. {n}"이나 "{n} / {total}"처럼 직접 쓸 수 있습니다. {n}은 페이지 번호, {total}은 마지막 번호입니다.
  • 크기와 색상: 작게, 보통, 크게 중에서 고르고 원하는 색을 지정합니다.

문서가 여러 파일로 나뉘어 있다면 먼저 PDF 합치기로 하나로 만들어야 번호가 이어집니다.

번호가 내용을 가리지 않게

많은 문서에는 바닥글에 이미 무언가(로고, 주소 등)가 있습니다. 번호가 그 위에 겹치면 다른 모서리로 옮기거나 위쪽으로 올리세요. 다운로드 전에 전후 모습으로 페이지마다 확인할 수 있고, 화살표로 페이지를 넘길 수 있습니다.

번호는 마지막에

번호는 각 페이지에 그려 넣어집니다. 나중에 페이지 순서를 바꾸거나 페이지를 추가하면 번호도 페이지와 함께 움직여 더 이상 차례대로 이어지지 않습니다. 그러니 번호는 마지막에 매기세요. 먼저 합치고, 순서를 정하고, 필요 없는 페이지를 뺀 다음 최종본에 번호를 넣으면 됩니다.

관공서나 회사에 내는 서류처럼 번호 표기 방식이 정해져 있다면 텍스트에 "No. {n}"처럼 입력하세요. 다른 문서의 번호를 이어 가야 한다면 "시작 번호"를 조정하세요.

모두 브라우저 안에서

번호는 기기 안에서 추가되며 PDF는 어떤 서버에도 업로드되지 않습니다. 문서의 텍스트는 그대로 텍스트로 남아 전처럼 검색하고 복사할 수 있고, 번호도 텍스트로 들어가 인쇄해도 선명합니다.

핵심 요약

  1. PDF 페이지 번호 매기기 열기. docusmart.online의 PDF 페이지 번호 매기기 도구를 열고 PDF를 고릅니다.
  2. 위치와 형식 고르기. 예: 오른쪽 아래에 "10페이지 중 1페이지".
  3. 필요한 설정 조정하기. 표지 번호 생략, 시작 번호, 크기, 색상을 정합니다.
  4. 번호 매기고 다운로드. 전후 모습을 확인하고 번호가 매겨진 PDF를 다운로드합니다.

자주 묻는 질문

표지에는 번호를 넣지 않을 수 있나요?

네. "처음 페이지 번호 생략"에 1(또는 건너뛸 페이지 수)을 입력하세요.

다른 번호부터 시작할 수 있나요?

네. "시작 번호"에 첫 번호, 예를 들어 25를 입력하세요.

번호 앞에 "No." 같은 글자를 넣을 수 있나요?

네. 텍스트에 "No. {n}"이라고 쓰면 페이지마다 {n} 자리에 해당 번호가 표시됩니다.
