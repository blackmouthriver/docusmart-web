PDF 페이지 순서를 바꾸는 방법

양면 스캔이 엇갈려 나왔거나, 맨 앞에 와야 할 첨부 자료가 뒤에 있거나, 같은 페이지가 두 번 들어갔을 때. PDF를 한 페이지씩 정리하는 방법입니다.

3분 분량2026년 11월 25일 업데이트

페이지마다 할 수 있는 일

PDF 페이지 순서 바꾸기에서는 각 페이지가 카드 한 장이 되며, 카드마다 다음 작업을 할 수 있습니다.

  • 이동: 원하는 자리로 끌어다 놓거나 앞뒤 화살표로 옮깁니다(휴대폰에서는 화살표가 더 편합니다).
  • 복제: 표지나 서명 페이지를 반복할 때 등에 씁니다.
  • 빈 페이지 추가: 그 페이지 뒤에 빈 페이지를 넣어 공간을 두거나 구역을 나눕니다.
  • 삭제: 필요 없는 페이지를 뺍니다.

단계별 방법

PDF 페이지 순서 바꾸기를 열고 PDF를 고릅니다. 필요한 순서가 될 때까지 페이지를 옮기세요. 카드마다 있는 번호("2쪽", "1쪽"…)가 원래 위치를 알려 주므로 헷갈리지 않습니다.

순서가 맞으면 "새 순서 적용"을 누르고 PDF를 다운로드합니다. 페이지는 그대로 복사되므로 텍스트도 화질도 바뀌지 않습니다.

정리하려는 페이지가 여러 파일에 나뉘어 있다면 먼저 PDF 합치기로 하나로 만든 뒤 여기서 순서를 정하세요.

페이지를 빼내려면 분할이 낫습니다

일부 페이지만 남기고 싶다면 PDF 분할이 더 빠릅니다. 가져갈 페이지만 표시하면 끝입니다. 순서 바꾸기는 문서 전체를 남기되 순서만 바꿀 때 씁니다.

자주 있는 경우

자동 양면 스캔이 안 되는 기기로 양면을 스캔하면 앞면이 모두 먼저 나오고 뒷면이 그 뒤에 나옵니다. 번갈아 놓으려면 마지막 페이지를 첫 페이지 뒤로, 끝에서 두 번째 페이지를 세 번째 페이지 뒤로 옮기는 식으로 끝까지 반복하세요. 화살표를 쓰면 금방 됩니다.

  • 맨 앞에 와야 할 첨부 자료: 첫 페이지 앞으로 옮기세요.
  • 두 곳에 필요한 서명 페이지: 복제해서 사본을 필요한 자리로 옮기세요.
  • 양면 인쇄 시 홀수 페이지에서 시작해야 하는 장: 그 앞에 빈 페이지를 추가하세요.

파일을 업로드하지 않고

새 순서는 브라우저 안에서 만들어집니다. 문서는 인터넷을 거치지 않고 어떤 서버에도 사본이 남지 않습니다. 그래서 기기 밖으로 나가면 안 되는 서류철, 진료 기록, 업무 문서도 안심하고 정리할 수 있습니다.

핵심 요약

  1. PDF 페이지 순서 바꾸기 열기. docusmart.online의 PDF 페이지 순서 바꾸기 도구를 열고 PDF를 고릅니다.
  2. 페이지 옮기기. 끌어다 놓거나 화살표를 씁니다. 복제, 빈 페이지 추가, 필요 없는 페이지 삭제도 할 수 있습니다.
  3. 적용하고 다운로드. "새 순서 적용"을 누르고 정리된 PDF를 다운로드합니다.

자주 묻는 질문

휴대폰에서도 순서를 바꿀 수 있나요?

네. 끌어다 놓기 외에도 페이지마다 앞뒤로 옮기는 화살표가 있어 손가락으로 다루기 쉽습니다.

링크와 양식은 유지되나요?

페이지는 내용과 함께 복사됩니다. 복잡한 양식이 있는 문서라면 결과를 확인하세요.

페이지 수에 제한이 있나요?

정해진 개수는 없습니다. 아주 큰 문서는 미리보기가 나타나기까지 조금 더 걸릴 수 있습니다.
