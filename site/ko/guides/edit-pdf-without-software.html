프로그램 설치 없이 PDF를 편집하는 방법

날짜를 고치거나, 빠뜨린 정보를 채우거나, 조항에 형광펜을 칠하거나, 무언가를 지우는 데 유료 프로그램은 필요 없습니다. 브라우저에서 PDF를 편집하는 방법입니다.

4분 분량2026년 11월 25일 업데이트

편집기의 도구

페이지 위쪽 도구 모음에 PDF 편집에서 넣을 수 있는 모든 것이 모여 있습니다.

  • 텍스트: 쓰고 싶은 곳을 누르고 아래 칸에 입력합니다. 글꼴, 크기, 굵게, 색상을 고를 수 있습니다.
  • 바꾸기: PDF에 이미 있는 텍스트를 눌러 고칩니다. 원래 텍스트는 가려지는 것이 아니라 문서에서 지워집니다.
  • 사각형, 원, 형광펜, 가리기: 표시하거나 강조하거나 흰색으로 덮습니다.
  • 그리기, 선, 화살표: 가리키거나 손으로 메모를 남깁니다.
  • 이미지와 링크: 도장이나 로고를 붙이거나, 웹페이지나 PDF의 다른 페이지로 연결합니다.

단계별 방법

PDF 편집을 열고 파일을 고릅니다. 도구 모음에서 "텍스트"를 고르고 넣을 위치를 누르면 옮길 수 있는 상자가 나타나고, 아래 패널에 입력하면 됩니다. "선택"으로는 어떤 요소든 눌러서 옮기거나 크기를 바꾸거나 삭제할 수 있습니다.

실수했다면 "실행 취소"를 쓰세요. 다 끝나면 "변경 사항 적용"을 누르고 편집한 PDF를 다운로드합니다.

텍스트는 라틴 문자, 키릴 문자, 그리스 문자, 중국어, 일본어, 한국어 등 어떤 문자든 쓸 수 있습니다. 이모지는 PDF에 저장되지 않습니다.

서명이나 양식 작성에는 전용 도구가 있습니다

서명이 필요하다면 PDF 서명에서 서명을 그리거나 입력하거나 이미지로 불러와 원하는 자리에 놓을 수 있습니다. PDF에 작성할 항목이 있다면 PDF 양식 작성이 항목을 하나씩 보여 주므로 위에 덧쓰는 것보다 편합니다.

고친 티가 나지 않게 하는 요령

문서에 이미 있는 텍스트를 고치려면 바꾸기를 쓰세요. 원래 텍스트를 지우고 그 자리에 새 텍스트를 넣습니다. 흰 상자로 덮기만 하면 옛 텍스트가 파일에 그대로 남습니다.

문서와 가장 비슷한 글꼴(Sans, Serif, Mono)을 고르고 크기를 맞추세요. 휴대폰에서는 요소를 천천히 옮기세요. 키보드 화살표 키로 위치를 바꿀 수도 있습니다.

파일은 내 손을 떠나지 않습니다

편집기는 모두 브라우저 안에서 동작합니다. PDF는 편집하는 동안에도 저장할 때도 어떤 서버에도 업로드되지 않습니다.

핵심 요약

  1. PDF 편집 열기. docusmart.online의 PDF 편집 도구를 열고 파일을 고릅니다.
  2. 넣을 것 고르기. 텍스트, 바꾸기, 도형, 형광펜, 그리기, 화살표, 이미지, 링크 중에서 고릅니다.
  3. 페이지에 배치하기. 페이지를 누르고 입력하거나 그린 뒤 "선택"으로 옮깁니다.
  4. 적용하고 다운로드. "변경 사항 적용"을 누르고 편집한 PDF를 다운로드합니다.

자주 묻는 질문

PDF에 이미 있는 텍스트를 바꿀 수 있나요?

네. "바꾸기"로 텍스트를 누르고 새 내용을 입력하면 원래 텍스트는 문서에서 지워집니다.

스캔한 PDF에서도 되나요?

텍스트, 도형, 그림을 위에 추가할 수 있습니다. 텍스트를 바꾸려면 PDF에 실제 텍스트가 있어야 하니, 사진 같은 PDF라면 먼저 OCR을 거치세요.

무언가를 설치해야 하나요?

아니요. 컴퓨터나 휴대폰의 브라우저에서 바로 됩니다.
