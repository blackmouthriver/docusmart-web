PDF 페이지 순서 바꾸기

페이지마다 미리 보기를 보면서 PDF의 각 페이지를 원하는 위치로 옮기고 필요 없는 페이지는 삭제하세요. 문서는 기기 밖으로 나가지 않습니다.

  • 파일 업로드 없음
  • 무료, 가입 불필요
  • 브라우저에서 작동

PDF 페이지 순서를 바꾸는 3단계

  1. PDF를 선택하거나 끌어다 놓으세요.
  2. 각 썸네일을 화살표로 옮기고, 필요 없는 페이지는 휴지통으로 삭제하세요.
  3. "새 순서 적용"을 누르고 PDF를 다운로드하세요.

파일이 내 기기 밖으로 나가지 않습니다

다른 온라인 도구와 달리 DocuSmart는 문서를 어떤 서버에도 올리지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다. 계약서, 청구서, 신분증도 안심하고 다룰 수 있습니다. 개인정보 처리방침 보기(스페인어).

자주 묻는 질문

순서를 바꾸면서 페이지를 삭제할 수 있나요?

네. 썸네일마다 삭제 버튼이 있으며, 최종 PDF에는 남겨 둔 페이지만 들어갑니다.

PDF가 서버에 업로드되나요?

아니요. 모든 작업은 브라우저 안에서 이루어지며 문서는 기기 밖으로 나가지 않습니다.

순서를 바꾸면 품질이 떨어지나요?

아니요. 페이지는 원래의 텍스트, 이미지, 크기 그대로 복사됩니다.

여러 PDF의 페이지를 합치고 싶다면요?

먼저 PDF 합치기 도구로 하나로 합친 다음, 결과 파일의 페이지 순서를 바꾸세요.
