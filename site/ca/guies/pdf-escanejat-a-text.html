Com passar un PDF escanejat a text que es pugui copiar i cercar

Un escaneig és una foto de cada pàgina: es pot llegir, però no se'n pot copiar el text ni cercar-hi una paraula. Amb l'OCR el text torna a ser text, sense haver-lo d'escriure de nou.

4 min de lecturaActualitzada el 26 de novembre del 2026

Què fa l'OCR

OCR vol dir reconeixement òptic de caràcters: el programa mira la imatge de cada pàgina i en reconeix les lletres. OCR: reconèixer text et dona dues coses alhora:

  • El text reconegut, per copiar-lo o baixar-lo en .txt o Word, amb la pàgina d'on surt cada part.
  • Un PDF cercable: el mateix escaneig, idèntic a la vista, amb una capa de text invisible a sobre. Hi pots seleccionar, copiar i cercar paraules amb Ctrl+F.

Pas a pas

Obre OCR: reconèixer text i tria el PDF escanejat (també serveix una foto en JPG, PNG o WebP). Tria l'Idioma del document: el reconeixement encerta molt més quan sap quin idioma ha d'esperar. Si el document barreja el seu idioma amb l'anglès, marca també aquesta casella.

Deixa marcat Genera també un PDF cercable si vols el PDF, i toca Reconeix el text. Veuràs l'avenç pàgina per pàgina. En acabar tens el PDF per baixar i, a sota, el text, que pots copiar o baixar en .txt o Word.

La primera vegada es baixa el model de l'idioma (uns segons) i queda desat al navegador: les vegades següents comença de seguida.

Com aconseguir un resultat millor

L'OCR llegeix el que veu. Un escaneig nítid, recte i amb bona llum es reconeix gairebé sense errors; una foto borrosa, amb ombres o molt petita, no. Si el reconeixement no és segur, DocuSmart t'avisa amb el percentatge de confiança perquè revisis el text.

  • Les pàgines girades es detecten i es llegeixen al dret automàticament.
  • Les pàgines que ja tenen text (un PDF mixt) es deixen tal com són, tret que marquis Reconèixer també les pàgines que ja tenen text.
  • Funciona amb lletra impresa. La lletra manuscrita gairebé mai no es reconeix bé.

Si el que vols és editar-lo al Word

Si el teu objectiu és corregir el document i no només copiar-ne el text, fes servir directament PDF a Word amb la casella d'OCR: reconeix les pàgines escanejades en el mateix pas i crea un .docx editable. I si el PDF cercable ha quedat massa pesant per enviar-lo, passa'l per Comprimir PDF.

El teu document no surt de l'equip

El reconeixement funciona al teu navegador amb Tesseract, un motor d'OCR de codi obert. El PDF no es puja a cap servidor, així que el pots fer servir amb documents d'identitat, historials clínics o extractes sense deixar-ne còpies enlloc.

Resum ràpid

  1. Obre l'OCR. Obre l'eina OCR: reconèixer text de docusmart.online i tria el PDF escanejat o una foto.
  2. Tria l'idioma. Tria l'idioma del document i marca si també té text en anglès.
  3. Reconeix el text. Toca Reconeix el text i espera que acabi cada pàgina.
  4. Baixa'l. Baixa el PDF cercable o copia el text, o baixa'l en .txt o Word.

Preguntes freqüents

Què és un PDF cercable?

És el teu mateix escaneig amb una capa de text invisible a sobre: es veu igual, però hi pots seleccionar, copiar i cercar paraules.

Quantes pàgines puc reconèixer?

Les que necessitis: es reconeixen una per una al teu navegador. Un document llarg triga més, però no hi ha límit de pàgines.

Reconeix diversos idiomes?

Dotze: castellà, anglès, portuguès, francès, italià, alemany, català, basc, rus, japonès, coreà i xinès. Si el document barreja el seu idioma amb l'anglès, marca aquesta casella.
