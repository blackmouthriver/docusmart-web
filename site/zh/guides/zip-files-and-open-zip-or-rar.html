如何把文件压缩成 ZIP，以及打开 ZIP 或 RAR

ZIP 能把很多文件合成一个：通过邮件发送更方便，有时体积也更小。在这里，你可以直接在浏览器中创建和打开压缩包，无需安装任何软件。

阅读约 4 分钟更新于 2026年11月27日

创建 ZIP：操作步骤

打开压缩文件（ZIP 和 7Z），添加文件（任何类型都可以），或用添加文件夹添加整个文件夹。填写 ZIP 的文件名，并选择压缩级别：快速、标准或最大。

点击创建 ZIP。你会看到一边是原来的文件，另一边是 ZIP，以及压缩前的总大小和现在的大小。

照片、视频和 PDF 本身已经压缩过，所以放进 ZIP 后体积几乎不会变小。Word 文档、电子表格和文本文件则能大幅缩小。

加密码或分卷

  • 用密码保护（AES-256）：没有密码就打不开 ZIP。ZIP 格式的密码只能包含不带重音的英文字母、数字和符号；如果想用中文或其他字符，请选择 7Z 格式。
  • 分卷：如果邮箱不接受这么大的文件，可以把它分成几个部分（.001、.002…）。打开时需要所有分卷，可以用 DocuSmart、7-Zip 或 WinRAR。
  • 7Z：压缩率比 ZIP 高，但有些设备需要安装软件才能打开。ZIP 在任何电脑和手机上都能直接打开，无需安装。

打开 ZIP、RAR 或 7Z

要取出压缩包里的内容，使用解压 RAR、ZIP 和 7Z。它可以打开 ZIP、RAR、7Z、TAR、GZ、BZ2 和 XZ，包括带密码的和分卷的压缩包。

你会看到压缩包内的文件列表和文件夹结构。下载前可以先预览某个文件，只提取选中的文件，或者全部一起下载。

如果你想让 PDF 变小

把 PDF 放进 ZIP 几乎不会让它变小。要真正减小 PDF 的体积，使用压缩 PDF，它会压缩 PDF 里的图片。

你的文件不会离开设备

压缩和解压都在浏览器的内存中完成：不会上传任何内容。文件非常大（几 GB）时，可能会很慢或内存不足；这种情况下，请分成几个 ZIP。

要点速览

  1. 添加文件. 打开 docusmart.online/zh/zip-files，添加文件或文件夹。
  2. 选择选项. 填写文件名、压缩级别，如有需要再设置密码。
  3. 创建 ZIP. 点击“创建 ZIP”，看看体积减少了多少。
  4. 下载. 下载 ZIP 或分享出去。

常见问题

没有 WinRAR 能打开 RAR 吗？

能。“解压 RAR、ZIP 和 7Z”可以在浏览器中打开 RAR、ZIP、7Z 等格式，无需安装。如果要新建压缩包，请用 ZIP 或 7Z。

为什么我的 ZIP 和原来差不多大？

因为照片、视频和 PDF 本身已经压缩过。ZIP 的作用主要是把它们合成一个文件，而不是让它们变小。

设置密码安全吗？

安全。采用 AES-256 加密，密码不会保存在任何地方：如果忘记了，就没有办法找回。
