计算和校验哈希（SHA-256、MD5）

确认文档未被修改：计算它的数字指纹，与你收到的值核对，或比较两个文件，文件始终不离开你的设备。

  • 无需上传文件
  • 免费、无需注册
  • 在浏览器中运行

计算或校验文件哈希的 3 个步骤

  1. 选择“计算”“校验”或“比较”，然后添加文件（任意类型：PDF、照片、ZIP…）。
  2. 选择算法（推荐 SHA-256），或粘贴你收到的哈希值；DocuSmart 会识别它是 SHA-256、SHA-512、SHA-1 还是 MD5。
  3. 复制哈希值，下载列表或 PDF 完整性证书，或查看是否一致。

你的文件不会离开你的设备

与其他在线工具不同，DocuSmart 不会把你的文档上传到任何服务器：一切都在浏览器中处理。处理合同、发票或身份证件也能完全放心。 阅读我们的隐私政策（西班牙语）.

常见问题

什么是哈希值？

它是文件的数字指纹：根据文件内容计算出的一串字母和数字。只要文件有变化，哪怕只改动一个字节，哈希值也会完全不同。

它有什么用？

用来确认别人发给你的文档就是原件（合同、招标文件、证据、下载文件），记录某个文件在某一日期的状态，或在不打开文件的情况下判断两个文件是否相同。

应该用哪种算法？

SHA-256 是当前的标准，也是推荐选择。SHA-512 更长。MD5 和 SHA-1 可用于与公布的校验和比对，但已不再能可靠地防止伪造。

什么是完整性证书？

一份包含文件名称、大小、日期和哈希值的 PDF。如果以后有人修改了其中某个文件，重新计算哈希值时就会与证书上的不一致。

我的文件会被上传吗？

不会。哈希值在你的浏览器中计算：文件永远不会离开你的设备。
