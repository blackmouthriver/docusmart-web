压缩文件（ZIP 和 7Z）

把文件和文件夹打包成一个 ZIP 或 7Z，方便发送或保存，需要的话还可以设置密码。

  • 无需上传文件
  • 免费、无需注册
  • 在浏览器中运行

将文件压缩为 ZIP 或 7Z 的 3 个步骤

  1. 添加文件或整个文件夹。
  2. 选择格式（ZIP 或 7Z）、压缩级别，需要时再设置密码。
  3. 点按“创建”，即可下载压缩文件。

你的文件不会离开你的设备

与其他在线工具不同，DocuSmart 不会把你的文档上传到任何服务器：一切都在浏览器中处理。处理合同、发票或身份证件也能完全放心。 阅读我们的隐私政策（西班牙语）.

常见问题

ZIP 还是 7Z？

ZIP 无需安装任何软件，在任何设备上都能打开。7Z 压缩率更高，设置密码后还会隐藏文件名；可用 7-Zip、WinRAR 或 DocuSmart 打开。

能创建 RAR 文件吗？

不能。RAR 是专有格式，其许可不允许其他软件创建。7Z 是免费的替代格式，压缩效果通常相当甚至更好。

密码有多安全？

使用 AES-256 加密。ZIP 的密码只能包含不带重音的英文字母、数字和符号；7Z 则可以使用中文等其他字符。

我的文件会上传到互联网吗？

不会。压缩在浏览器中完成：你的文件永远不会离开你的设备。
