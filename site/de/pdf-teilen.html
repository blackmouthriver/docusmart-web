PDF teilen

Extrahiere die benötigten Seiten oder speichere jede Seite als eigene Datei, direkt im Browser.

  • Ohne Datei-Upload
  • Kostenlos, ohne Anmeldung
  • Läuft im Browser

Ein PDF in 3 Schritten teilen

  1. Wähle das PDF, das du teilen möchtest.
  2. Tippe auf die Seiten, die du behalten willst, gib einen Bereich wie „1-3, 5“ ein oder wähle „Jede Seite einzeln“.
  3. Lade das Ergebnis herunter: ein PDF mit den gewählten Seiten oder ein .zip mit einer Seite pro Datei.

Deine Dateien verlassen dein Gerät nicht

Anders als andere Online-Werkzeuge lädt DocuSmart deine Dokumente auf keinen Server hoch: Alles wird in deinem Browser verarbeitet. Du kannst es bedenkenlos mit Verträgen, Rechnungen oder Ausweisdokumenten nutzen. Unsere Datenschutzerklärung lesen (auf Spanisch).

Häufige Fragen

Wie extrahiere ich nur einige Seiten?

Tippe sie in den Miniaturansichten an oder gib einen Bereich ein, zum Beispiel „2-4, 7“, oder „5-“ für Seite 5 bis zum Ende.

Wird das Original-PDF verändert?

Nein. Es wird immer eine neue Datei erstellt; das Original bleibt unverändert auf deinem Gerät.

Ist das sicher für private Dokumente?

Ja. Die Datei wird nicht ins Internet hochgeladen: Alles passiert in deinem Browser.
