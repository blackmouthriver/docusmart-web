Comment créer un code QR gratuit

Un QR envoie les gens vers votre page, ouvre une discussion WhatsApp ou connecte au Wi-Fi sans rien taper. Créez-le en quelques secondes ; il n'expire pas et ne dépend d'aucun serveur.

4 min de lectureMis à jour le 27 novembre 2026

Pas à pas

Ouvrez Créer et lire des codes QR et choisissez ce qu'il va contenir : URL, Texte, E-mail, Téléphone, WhatsApp, SMS, Lieu, Wi-Fi, Contact ou Événement. Saisissez les informations (pour un lien, l'adresse complète avec https://).

Appuyez sur Générer le QR. Le code apparaît aussitôt et vous pouvez le télécharger en PNG, en SVG (vectoriel, net à l'impression quelle que soit la taille), en PDF (10 cm), le copier comme image ou l'imprimer.

Avant d’imprimer cent prospectus, scannez le QR avec votre téléphone pour vérifier qu’il ouvre bien ce que vous attendez.

Ce que permet chaque type

  • WhatsApp : saisissez le numéro avec l'indicatif du pays (33 pour la France, par exemple) et, si vous voulez, un message. En le scannant, la discussion s'ouvre avec le message déjà écrit.
  • Wi-Fi : le nom du réseau, la sécurité et le mot de passe. Vos invités se connectent sans que vous ayez à le dicter.
  • Contact : nom, téléphone, e-mail et entreprise. En le scannant, le téléphone propose de l'enregistrer dans les contacts.
  • Lieu : une adresse ou des coordonnées qui s'ouvrent dans la carte.
  • Événement : titre, lieu, début et fin, pour l'ajouter à l'agenda.

Donnez-lui votre style

Dans Personnaliser le design, vous changez la couleur du code et du fond (ou vous le laissez transparent pour le poser sur votre visuel), vous placez votre logo au centre et vous choisissez la taille de l'image. Si les couleurs manquent de contraste, DocuSmart vous prévient, car un appareil photo pourrait ne pas le lire.

Avec Protégé, le contenu du QR est chiffré par un mot de passe (AES-256) : seule la personne qui le connaît peut l'ouvrir, dans DocuSmart. Et avec Plusieurs QR depuis une liste, vous en générez beaucoup d'un coup, un par ligne ou à partir d'un CSV, par exemple pour les tables d'un restaurant ou les étiquettes d'un inventaire.

Pour lire un QR

Si vous devez en lire un, utilisez Lire un code QR : avec la caméra, depuis une photo ou une capture d'écran, ou depuis un PDF. Avant d'ouvrir un lien, il vous montre où il mène et vous avertit s'il semble trompeur.

Votre QR n'expire pas

Le code est généré dans votre navigateur et contient directement les données, sans passer par un lien intermédiaire. C'est pourquoi il n'expire pas, n'a pas de limite de scans et personne d'autre ne voit ce que vous y avez mis. Les QR que vous créez sont conservés dans l'Historique, uniquement dans votre navigateur.

En bref

  1. Choisissez le type. Allez sur docusmart.online/fr/generateur-code-qr et choisissez URL, WhatsApp, Wi-Fi ou un autre type.
  2. Saisissez les informations. Indiquez le lien, le numéro ou les informations du réseau.
  3. Générez le QR. Appuyez sur Générer le QR et, si vous voulez, changez la couleur ou ajoutez votre logo.
  4. Téléchargez-le. Téléchargez-le en PNG, SVG ou PDF, ou imprimez-le.

Questions fréquentes

Le code QR expire-t-il ?

Non. Les données sont dans le code lui-même, sans lien intermédiaire : il fonctionne pour toujours et sans limite de scans.

Quel format utiliser pour l'impression ?

Le SVG : il est vectoriel et reste net à n'importe quelle taille, d'une carte de visite à une affiche. Il existe aussi un PDF de 10 cm.

Puis-je mettre mon logo dans le QR ?

Oui, dans Personnaliser le design. Le logo se place dans un cercle au centre et le code reste lisible.
