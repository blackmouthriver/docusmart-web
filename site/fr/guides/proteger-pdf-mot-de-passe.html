Comment protéger un PDF par mot de passe

Un PDF contenant vos données personnelles, financières ou médicales qui circule par e-mail ou par messagerie peut finir n'importe où. Ajouter un mot de passe prend une minute et empêche qu'il soit ouvert par la mauvaise personne.

4 min de lectureMis à jour le 18 novembre 2026

Quand protéger un PDF

  • Pièces d'identité, relevés bancaires, fiches de paie ou avis d'imposition.
  • Dossiers médicaux, résultats d'analyses ou arrêts de travail.
  • Contrats ou propositions que vous ne voulez pas voir circuler.
  • Tout fichier envoyé par un canal que vous ne maîtrisez pas, comme un e-mail qui peut être transféré ou un groupe de discussion.

Pas à pas

Ouvrez Protéger un PDF et choisissez le document. Saisissez le mot de passe deux fois.

Décidez de ce qui est autorisé une fois le PDF ouvert : imprimer, copier le texte ou le modifier. Touchez « Protéger le PDF » et la version chiffrée se télécharge. Elle s'ouvre avec Adobe Acrobat, Chrome, Edge et l'app DocuSmart, qui demandent le mot de passe.

Un bon mot de passe et comment le transmettre

  • Utilisez au moins 10 caractères ; une courte phrase avec des chiffres est facile à retenir et difficile à deviner.
  • N'utilisez ni votre numéro de sécurité sociale ni votre date de naissance : c'est la première chose qu'on essaierait.
  • N'envoyez jamais le mot de passe par le même canal que le PDF. Si le fichier part par e-mail, envoyez le mot de passe par SMS ou donnez-le par téléphone.

Conservez le mot de passe en lieu sûr. Si vous l'oubliez, il est impossible de le récupérer : même DocuSmart ne peut pas ouvrir le PDF, car le mot de passe ne quitte jamais votre appareil.

Ce que protège chaque option

Le mot de passe d'ouverture est la vraie protection : sans lui, le fichier chiffré est illisible. Les autorisations (imprimer, copier, modifier) sont autre chose : elles indiquent aux lecteurs PDF ce qu'ils doivent permettre une fois le document ouvert.

Les logiciels sérieux respectent ces autorisations, mais une personne qui a déjà le mot de passe peut les retirer avec certains outils. Utilisez-les pour éviter les copies accidentelles ou les modifications involontaires, pas comme seule barrière. Si quelqu'un ne doit pas voir une information, ne lui donnez pas le mot de passe ou caviardez cette information avant d'envoyer le fichier.

Un mot de passe, ce n'est pas un caviardage

Le mot de passe empêche d'ouvrir le fichier, mais la personne qui le connaît verra tout le contenu. Si vous devez partager un document en masquant seulement certaines informations (un numéro de compte, une adresse), utilisez Caviarder un PDF : l'outil supprime réellement le texte sous les zones masquées, au lieu de poser un simple rectangle noir par-dessus.

Retirer le mot de passe plus tard

Si vous avez besoin plus tard d'une copie non protégée, Déverrouiller un PDF retire le mot de passe, à condition que vous le connaissiez. Utilisez-le uniquement avec vos propres documents ou ceux que vous avez le droit de modifier.

En bref

  1. Ouvrez Protéger un PDF. Ouvrez l'outil Protéger un PDF par mot de passe sur docusmart.online et choisissez le document.
  2. Saisissez le mot de passe. Saisissez-le deux fois pour le confirmer.
  3. Choisissez les autorisations. Indiquez si l'impression, la copie ou la modification sont autorisées.
  4. Protégez et téléchargez. Touchez « Protéger le PDF » et le document chiffré se télécharge.

Questions fréquentes

Est-ce vraiment sûr ?

Le chiffrement utilisé est l'AES-256, le standard le plus robuste pour les PDF. La sécurité réelle dépend surtout d'un mot de passe difficile à deviner.

Mon mot de passe est-il envoyé à un serveur ?

Non. Le chiffrement se fait dans votre navigateur ; ni le fichier ni le mot de passe ne quittent votre appareil.

Puis-je retirer le mot de passe du PDF de quelqu'un d'autre ?

Seulement si vous connaissez le mot de passe. DocuSmart ne casse pas les mots de passe d'ouverture.
